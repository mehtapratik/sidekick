## Search

- The MVP searches **title and metadata only**: display name, type, provider, status and tags. Body text is never searched in the MVP; full-text body search is a post-MVP advanced search.
- Postgres full-text search plus `pg_trgm` for typos and partial words. Exact tag matches use the tag tables, not text search.
- Filters by type, provider, status and tag. Results page by cursor.
- Search uses the one central index until body-text search arrives ([[06-decisions/technical/synergy-store-choices|store choices]]). Embeddings arrive with the AI layer in Phase 6.

## Backlinks

"Who references me" is a first-class query: every relationship pointing at an entity, with its label, type (shown by its inverse name), kind and state. It pages by cursor, because a popular entity can have thousands.

## Linking and the picker

The link picker searches the same index. It greys out entities that would close a reference cycle and refuses targets in modules the account doesn't have.
