A plan in War Room says "based on what I learned about deep work". Six months later, the Taxila note it leaned on has been rewritten. The plan doesn't know. It still reads as well-founded, and nothing in Sidekick will tell me it isn't until I act on it and find out the hard way.

That is the problem Synergy solves. Each Sidekick module holds a different kind of information: Taxila holds knowledge, War Room holds plans, Alter Ego holds conversations, Core Drive holds values. Each one is useful alone. The value I'm after comes from the connections between them, the way an iPhone, a Mac and a pair of AirPods are worth more together than apart. Connections bring a second problem with them, though. A plan that cites a note is only as good as that note, and when the note changes or goes out of date, the plan should know.

Synergy makes connections cheap and keeps them honest. It is the substrate every module builds on: one way to link anything to anything, one way to tag it, one way to show a link, and one way to find what is linked.

## Goals

- **Connect.** Any entity in any module can link to any other, and every entity knows who references it.
- **Keep true.** A reference remembers what its target looked like when it was made, and says so when the target changes, is deprecated, is superseded or is gone. Sources telling the same truth are linked, never copied, so they can't quietly drift apart.
- **Render.** The same link shows as a line of text, a card or the whole target in place, for people. Bots and agents get the same data as structured JSON through the same API.
- **Find.** Titles, types, statuses and tags are searchable across every module.

## Principles this feature stands on

- [[principle.individual-first|Individual First]]. Sidekick serves one person's workflow. Every field the user can fill is optional, and the user decides what a link means, when a change matters and when to act on one. The system can suggest. It never decides for them.
- [[principle.one-interface|One Interface]]. Sidekick's own screens, bots, jobs and agents all use the same guarded API. Every rule in this PRD holds for every consumer, because there is only one path.
- [[principle.cost-to-add-later|Cost to Add Later]]. The MVP can look primitive. Its foundations can't be: anything that would force a data migration or a rewrite of a shared component ships now.

## Out of scope

- Teamwork and collaboration. Sidekick is for one person for the next four to five years.
- References between users. Designed not to be ruled out, built after the MVP.
- Tracking who reads a published post from outside Sidekick.
- Automation between modules. That is Factory's job; Synergy only records what changed.
