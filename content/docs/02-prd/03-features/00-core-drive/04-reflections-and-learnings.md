Core Drive to follow reflective writing pattern — any deviation between core drive entry and actual observation triggers retrospection—actual observation becomes a case study — it refines related core drive entries to get closer to reality—

Core Drive entries are not some ideal or righteous state to be reached, but grounded on reality that can be approached and while pushing the user gently beyond their comfort zone to help them get better.
