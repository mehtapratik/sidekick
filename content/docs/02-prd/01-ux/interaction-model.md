# MVP Scope 
A single VS Code style command box in the center of the page — eliminate site layout and navigation design concerns altogether — just focus on core product experience — 

## Consequence
Keyboard focused interaction model — new users find it hard to discover features — an acceptable tradeoff for MVP to test market with limited number of internal adopters.
