The `profiles` table lives in `packages/core`. It contains:

- `id` — same UUID as `auth.users.id` (not auto-generated by the profiles table); foreign key to `auth.users(id)` with `ON DELETE CASCADE`, so deleting an auth user deletes the profile
- `email` — copied from `auth.users.email` at creation time
- `createdAt` — column default `now()` when the trigger inserts the row

RLS is enabled and forced on `profiles`. The canonical user-owns-rows policy applies. Rows are created only by the [[profile-creation-postgres-trigger|auth trigger]].

`profiles` is deliberately not soft-deleted: closing an account must be able to erase personal data, and the cascade from `auth.users` is part of that path.
