## Personal Information ( $p$ )

Information created by you and accessible internally to Sidekick for decision-making.

## Public Information ( $P$ )

Information not created by you, but available for consumption—such as news, web content, published articles, and the company wiki.

## Therefore information $I = p + P$.

Which represents every information source (both public and private) accessible to the system.
